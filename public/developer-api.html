API para Desarrolladores

Integra FacilitoTools en tu propio sistema. Genera boletas y facturas electrónicas desde tu backend, ecommerce o app móvil con una API REST simple y autenticada por API Key. Cero impacto en la interfaz actual para usuarios normales.

Obtén tu API Key en 3 pasos

1️⃣ Inicia sesión con tu cuenta.
2️⃣ Baja hasta la sección «Tus API Keys».
3️⃣ Escribe un nombre (ej. Producción Web) y pulsa el botón verde «Crear API Key». La clave completa se mostrará una sola vez — cópiala y guárdala de inmediato.

Documentación de la API

Base URL: https://facilitotools.com/v1 · Todas las requests requieren Authorization: Bearer <API_KEY>

GET /v1/me

Devuelve información de la cuenta asociada a la API Key (uid y plan). Útil para validar credenciales.

curl https://facilitotools.com/v1/me \
  -H "Authorization: Bearer ft_live_TU_API_KEY"
// Validar tu API Key
const res = await fetch('https://facilitotools.com/v1/me', {
  headers: { 'Authorization': `Bearer ${process.env.FT_API_KEY}` }
});
const json = await res.json();
console.log(json);
import requests
r = requests.get(
  "https://facilitotools.com/v1/me",
  headers={"Authorization": f"Bearer {API_KEY}"}
)
print(r.json())
// Validar API Key
$ch = curl_init("https://facilitotools.com/v1/me");
curl_setopt($ch, CURLOPT_HTTPHEADER, [
  "Authorization: Bearer " . $API_KEY
]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$resp = json_decode(curl_exec($ch), true);
curl_close($ch);
var_dump($resp);
GET /v1/templates

Lista las plantillas disponibles (Moderna Azul, Elegante Grafito, Corporativa Índigo, Premium Esmeralda).

curl https://facilitotools.com/v1/templates \
  -H "Authorization: Bearer ft_live_TU_API_KEY"
POST /v1/comprobantes/build

Normaliza el payload y devuelve el JSON completo (totales, QR, items enriquecidos). NO consume cupo, NO genera PDF.

curl -X POST https://facilitotools.com/v1/comprobantes/build \
  -H "Authorization: Bearer ft_live_TU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "documentType": "boleta",
    "templateId": "moderna",
    "issuer": { "businessName": "Mi Tienda", "documentNumber": "20123456789" },
    "customer": { "name": "Juan Pérez", "documentType": "DNI", "documentNumber": "12345678" },
    "items": [{ "description": "Servicio", "quantity": 1, "unitPrice": 100, "unitLabel": "UND" }]
  }'
POST /v1/comprobantes/preview

Genera la vista previa del comprobante en HTML (sin consumir cupo). Útil para previsualizar antes de generar el PDF.

curl -X POST https://facilitotools.com/v1/comprobantes/preview \
  -H "Authorization: Bearer ft_live_TU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ ... payload ... }'
POST /v1/comprobantes/pdf

Genera el PDF final y lo devuelve como application/pdf. Consume 1 comprobante del plan.

curl -X POST https://facilitotools.com/v1/comprobantes/pdf \
  -H "Authorization: Bearer ft_live_TU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ ... payload ... }' \
  --output boleta.pdf
// Generar PDF y guardarlo localmente
const fs = require('fs');
const payload = {
  documentType: 'boleta',
  templateId: 'moderna',
  issuer: { businessName: 'Mi Tienda', documentNumber: '20123456789' },
  customer: { name: 'Juan Pérez', documentType: 'DNI', documentNumber: '12345678' },
  items: [{ description: 'Servicio', quantity: 1, unitPrice: 100, unitLabel: 'UND' }]
};
const res = await fetch('https://facilitotools.com/v1/comprobantes/pdf', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.FT_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify(payload)
});
const buf = Buffer.from(await res.arrayBuffer());
fs.writeFileSync('boleta.pdf', buf);

Esquema del payload (común a los 3 endpoints de comprobantes)

{ // Campos requeridos marcados con *
  "documentType": "boleta" | "factura",            // *
  "templateId":  "moderna" | "elegante" | "corporativa" | "premium",
  "issuer": {
    "businessName":   "Razón social",                // *
    "documentNumber": "RUC o DNI",
    "address":        "...",
    "phone":          "...",
    "email":          "...",
    "website":        "...",
    "logoDataUrl":    "data:image/png;base64,..."      // solo planes pagos
  },
  "customer": {
    "name":           "Cliente",                       // *
    "documentType":   "DNI"|"RUC"|"CE"|"Pasaporte",
    "documentNumber": "...",
    "email", "phone", "address"
  },
  "items": [{
    "description": "...", "quantity": 1, "unitPrice": 100,
    "unitLabel":  "UND", "sku": "opcional"
  }],
  "pricesIncludeTax": true,                            // true = IGV ya está en unitPrice
  "taxRate":         0.18,                                  // 18% por defecto (Perú)
  "currency":        "PEN",
  "paymentMethod":   "Pago único",
  "notes":           "Observaciones opcionales",
  "series", "correlative"                                      // opcionales, default B001 / F001
}

Los códigos de error más comunes:

  • 401 AUTH_REQUIRED – falta el header Authorization.
  • 401 AUTH_INVALID – la API Key no coincide.
  • 401 AUTH_REVOKED – la clave fue revocada.
  • 403 PLAN_REQUIRED – plan gratuito, la API requiere un plan pago.
  • 403 LIMIT_REACHED – se agotó el cupo del plan.
  • 429 – demasiadas requests, espera 1 minuto.
