3. Principio de "Residuo Cero" y Tratamiento del Historial de Consultas

Para la máxima protección legal y privacidad tanto del usuario registrado como de los terceros cuyos datos son consultados en la Plataforma, FacilitoTools opera bajo una Política de Residuo Cero (Zero-Data Retention Policy) respecto al historial de datos de consulta.

A. Tratamiento de Consultas de Validación

Cuando realiza una consulta (DNI, RUC, Cédula o Telefonía):

  • Paso de Datos: La Plataforma actúa únicamente como un conducto técnico intermedio (data pipeline). Recibe el parámetro de búsqueda, procesa la petición ante la API correspondiente y devuelve el resultado a la pantalla del usuario.
  • Sin Almacenamiento en Servidor: FacilitoTools no guarda ni registra en servidores externos, bases de datos remotas ni en la nube el contenido de los resultados obtenidos (nombres, direcciones, estados tributarios o números de teléfono).
  • Persistencia Local (LocalStorage): Todo el historial de consultas de validación se almacena exclusivamente en el navegador del usuario mediante la tecnología LocalStorage de su dispositivo personal.
  • Control Total del Usuario: El usuario conserva el control absoluto de dicho historial, pudiendo filtrarlo, consultarlo o eliminar registros individuales o totales en el momento que lo desee mediante los botones "Limpiar" y "Eliminar este registro". Si el usuario borra la caché o datos de navegación de su explorador, dicho historial se eliminará definitivamente sin posibilidad de recuperación por parte del Titular.

B. Tratamiento de la Emisión de Boletas

  • Procesamiento Cliente (Client-Side): La información utilizada para la confección, maquetación y llenado de boletas de venta no se almacena en ninguna base de datos centralizada ni en la nube de la Plataforma.
  • Generación Local: El guardado e historial de boletas generadas reside estrictamente en el almacenamiento local del dispositivo (LocalStorage) desde el cual opera el usuario.

4. Datos Personales Recopilados y Almacenamiento en Firestore

Para la creación de cuentas, autenticación de usuarios y administración técnica del servicio, FacilitoTools recopila únicamente los datos estrictamente necesarios para la prestación del servicio.

A. Registro y Autenticación

Durante la creación de cuenta o inicio de sesión en la Plataforma, recopilamos:

  • Nombre completo o nombre de usuario visible.
  • Dirección de correo electrónico.
  • Contraseña encriptada (en caso de registro directo con correo/contraseña).
  • Identificador único de usuario (UID) e información básica del perfil cuando el usuario opta por ingresar mediante proveedores de identidad de terceros (Google Sign-In o GitHub OAuth).

B. Base de Datos Cloud

Estos datos de perfil y autenticación se almacenan en la base de datos Google Firebase Firestore, bajo estrictas medidas de seguridad, reglas de autenticación y controles de acceso cifrados.

C. Control de Consumo y Cupos

Adicionalmente, en la base de datos Firestore se guarda el registro del saldo de cupos y las métricas numéricas de consumo del usuario (cantidad de consultas realizadas y límite disponible según su plan) para prevenir abusos y gestionar el acceso a los servicios de la API.

5. Pasarela de Pagos, Compras Automáticas y Gestión de Planes

FacilitoTools pone a disposición de sus usuarios una interfaz transparente de adquisición de servicios para el acceso a las funciones de consulta.

A. Modalidad de Pago (Sin Suscripciones Recurrentes)

  • Cobros Únicos: La adquisición de saldo o planes dentro de FacilitoTools no constituye una suscripción de renovación automática.
  • Prueba Gratuita: Al registrarse, el usuario puede disponer de un cupo de prueba gratuita para evaluar la Plataforma.
  • Recargas por Recargo/Paquetes: Una vez agotada la prueba, el usuario puede comprar paquetes de consultas o asignación de cupos de forma puntual según sus necesidades operativas. No se realizarán cargos periódicos ni débitos automáticos no autorizados en el futuro.

B. Integración con la API de Mercado Pago

  • Aprovisionamiento Instantáneo: Los pagos son procesados de forma 100% automática a través de la API oficial de Mercado Pago. Una vez confirmado el pago por la pasarela, los cupos se acreditan de manera inmediata en la cuenta del usuario.
  • Métodos de Pago Aceptados: Se aceptan transferencias mediante Yape y todo tipo de Tarjetas de Débito y Crédito procesadas por la pasarela.
  • No Retención de Datos Financieros: FacilitoTools jamás captura, procesa ni almacena los datos de sus tarjetas de crédito/débito, claves secretas ni tokens bancarios. Todas las transacciones financieras son gestionadas en los servidores seguros y bajo los estándares de encriptación PCI-DSS de Mercado Pago.

6. Transferencia de Datos a Terceros y Servicios Conectados

FacilitoTools no vende, alquila ni comercializa datos personales a terceras empresas. Para la operatividad técnica del sitio, la Plataforma se conecta con las siguientes entidades:

  • Google Firebase (Firestore / Authentication): Para la gestión de cuentas, autenticación de usuarios y registro de cupos de uso.
  • Mercado Pago (API): Para la pasarela de pagos en línea.
  • APIs de Consulta Externa (APISPERU y fuentes oficiales): Para la canalización en tiempo real de las respuestas de validación.
